# Prompt archive

Complete original generation prompts for the current hero and avatar have not been recovered. No reconstructed prompt is stored as their original.

For future work, create a directory named `YYYY-MM-DD-short-description/` with:

| File | Contents |
| --- | --- |
| `prompt.txt` | Exact submitted prompt, copied verbatim |
| `record.md` | Date, purpose, prompt provenance, available tool/model details, exact reference asset revisions and checksums, output files, and approval status |
| `references/` | Referenced images that may be published, or a manifest identifying their repository paths and immutable revisions |
| `outputs/` | Approved outputs and any explicitly retained alternatives |

Use [record-template.md](record-template.md) as a recording form. It is a template, not generation history. A newly authored prompt based on the guidelines must be labeled as new. Record unknown metadata as unknown. Keep credentials, account details, private links, and unpublished project information out of this archive.
