# Tokyo Tiny Builders Club

A small club building tools for building software.

Our current focus is autonomous software development and the infrastructure around coding agents, for individual developers and small teams.

## About the club

Tokyo Tiny Builders Club was started by [@shimpeiws](https://github.com/shimpeiws).

Contributions, ideas, and fellow builders are always welcome.
