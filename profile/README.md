# Tokyo Tiny Builders Club

A small club building tools for building software.

Our current focus is autonomous software development and the infrastructure around coding agents, for individual developers and small teams.

We build these tools to help small teams keep their codebases understandable and maintainable as coding agents take on more development work.

## Projects

### [taisan](https://github.com/ttbc-dev/taisan)

A self-hosted orchestration loop for coding agents. You choose the work and define its intent and constraints; taisan coordinates implementation, pull requests, review, and bounded fix cycles, while keeping progress inspectable and making the need for human intervention explicit.

Workers and work-selection strategies connect through replaceable adapters, so the orchestration can evolve independently of any particular coding agent.
